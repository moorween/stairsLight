# Stairs Light

Проект PlatformIO для двухъядерного ESP32, Arduino-ESP32 3.x.

- Аппаратная конфигурация — `include/HardwareConfig.h`.
- Алгоритм движения и фильтры PIR независимы от Arduino. После изменения логики
  выполнять `sh tools/test.sh`.
- Сборки: `pio run -e esp32-usb` и `pio run -e esp32-ota`.
- Не загружать прошивку на устройство без запроса пользователя.
- Сетевые библиотеки вызываются только сетевой задачей; LED и PIR принадлежат
  задаче света. Не передавать LED-кадры между задачами.
- Не коммитить `Secrets.h`, пароли, `.pio` и локальные окружения сборки.

## subjectLab

Версия закреплена в `platformio.ini`. Перед использованием API читать
`.pio/libdeps/<окружение>/subjectLab/docs/API.md` и соответствующие заголовки
`src/*.h` установленной версии. Если зависимости отсутствуют: `pio pkg install`.
Без локальной копии — документация тега v1.1.0 в репозитории moorween/subjectLab.
Не менять исходники в `.pio/libdeps`; изменения самой библиотеки делаются
в её отдельном репозитории. `Async` используется только из задачи-владельца.
Для важных команд проверять результат `Action::call`, для диагностики следить
за `CoreLoop::dropped()`.
